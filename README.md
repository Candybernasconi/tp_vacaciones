# Bot_vacaciones
DESCRIPCION
Este proyecto es un bot que permite gestionar consultas de empleados de 
una manera automatizada mediante un sistema de estados donde el 
usuario ingresa y hace consultas y recibe respuestas del
sistema para poder solucionar problemas como seria 
en este caso la gestion de vacaciones. 


.FUNCIONALIDADES
Responde consultas del usuario 
Manejo de estados(inicio,consulta,error,finalizacion)
Validacion de datos ingresados
Respuestas automaticas

.COMO EJECUTAR EL PROYECTO
1. Asegurate de estar ubicado en la carpeta del proyecto desde tu terminal.
2. Ejecuta el siguiente comando para inicar el programa:
3.  bash
4.  python tp_oe_vacaciones.py
